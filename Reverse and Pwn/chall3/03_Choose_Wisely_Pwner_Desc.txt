IITCTF — Challenge 4
======================

Challenge Title
---------------
Choose Wisely, Pwner

Category
--------
Pwn

Difficulty
----------
Hard

Description
-----------
You are faced with a series of choices.

Some choices look friendly.

Some choices lead somewhere... less friendly.

The program hides a vulnerable path behind the choices. If you
can understand the program, find the vulnerability, and exploit
it correctly, there may be something waiting in the treasure room.

Choose wisely.

Files
-----
pwnventure

How to Run Locally
------------------
    chmod +x pwnventure
    ./pwnventure

Remote Connection
-----------------
The organizer should provide a remote TCP service.

Connect using:

    nc <HOST> <PORT>

Objective
---------
- Explore the program and understand its different paths.
- Reverse engineer the relevant functions.
- Identify the vulnerable input.
- Determine the required memory corruption/control-flow
  condition.
- Build an exploit.
- Use the exploit against the remote service.
- Retrieve the flag.

Recommended Tools
-----------------
- GDB
- pwndbg or GEF
- checksec
- Python
- pwntools
- Ghidra (optional)

Hints
-----
- Not every choice is equally useful.
- Pay attention to what happens when you reach the treasure room.
- Inspect input-handling functions carefully.
- Check the binary's security mitigations before developing
  the exploit.
- The intended solution requires exploitation rather than simply
  guessing the flag.

Flag Format
-----------
IITCTF{...}

Organizer Notes
---------------
This challenge should be hosted as a remote TCP service.

Distribute the `pwnventure` binary as an attachment so players
can analyze it locally.

The remote service should run in an isolated environment.

Do NOT expose the organizer's development machine directly.
